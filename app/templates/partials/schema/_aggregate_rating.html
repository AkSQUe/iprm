{# AggregateRating + вузли Review для схеми курсу. Джерело для СЕРЕДНЬОГО і КІЛЬКОСТІ -- rating_count/rating_average, які в'ю рахує ОКРЕМИМ SQL-запитом (COUNT/AVG) за ВСІМА опублікованими живими відгуками курсу, а не з переданого списку reviews: той список обрізаний лімітом показу карток (.limit(6)) і рахувати AggregateRating з нього означало б, що керований адміном sort_order міг "закріпити" 5.0, приховавши решту відгуків від Google -- саме той ризик фабрикації, якому ця задача покликана запобігти. rating_count == 0 -- єдина ознака "відгуків немає": тоді макрос не додає НІЧОГО, розмітки не буде взагалі. Демо-цитати з головної сюди потрапити не можуть -- вони не є рядками БД. Вузли review (масив, що показується в структурованих даних) будуються з `reviews` -- це той самий обрізаний список, що йде на сторінку: вузли структурованих даних мають відповідати тому, що бачить відвідувач. Макрос МУТУЄ переданий schema, а не повертає JSON: схема курсу збирається dict-ом вище по шаблону, і вливати фрагмент рядком означало б парсити його назад. #} {% macro apply_rating(schema, reviews, rating_count, rating_average) -%} {%- if rating_count -%} {%- set _nodes = [] -%} {%- for review in reviews -%} {%- set _discard = _nodes.append({ '@type': 'Review', 'author': {'@type': 'Person', 'name': review.t('author_name')}, 'reviewRating': { '@type': 'Rating', 'ratingValue': review.rating, 'bestRating': 5, 'worstRating': 1, }, 'reviewBody': review.t('text'), 'datePublished': review.created_at.date().isoformat(), }) -%} {%- endfor -%} {%- set _discard = schema.update({ 'aggregateRating': { '@type': 'AggregateRating', 'ratingValue': (rating_average | float) | round(1), 'reviewCount': rating_count, 'bestRating': 5, 'worstRating': 1, }, 'review': _nodes, }) -%} {%- endif -%} {%- endmacro %}
