{#- Сума з символом валюти. Гривню показуємо символом (₴), як усюди на сайті: код "UAH" у картці курсу виглядає як виписка з банку, а не як ціна. Інші валюти лишаються кодом -- символів для них ми не тримаємо. Саме число форматує фільтр `amount` (app/services/money.py), а не `| int`: той округлював униз, і залишок 0.60 після промокоду друкувався як "0" (REG-4299/4300). Копійки показуємо лише тоді, коли вони є. Використання: {% from 'partials/_money.html' import money %} {{ money(course.effective_price, course.currency) }} {{ money(price, currency, unit_class='iprm-online-buy__currency') }} unit_class -- клас для символу, коли він має бути дрібнішим за число. Порожнє значення дає порожній рядок, а не самотній знак валюти: `| int` перетворював None на 0, і незадана ціна друкувалась як "0 ₴". -#} {%- macro money(value, currency='UAH', unit_class=None) -%} {%- set text = value | amount -%} {%- if text -%} {%- set unit %}{% if currency == 'UAH' %}₴{% else %}{{ currency }}{% endif %}{% endset -%} {{- text }} {% if unit_class %}{{ unit }}{% else %}{{ unit }}{% endif -%} {%- endif -%} {%- endmacro -%}
