Налаштування

Публічний ключ. Вшивається у HTML сторінок.

Серверний ключ. Зберігається зашифрованим у БД (Fernet/SECRET_KEY).

Стандарт Google -- 0.5. Нижче = бот. Вище = жорсткіше, ризик false-positives.

Без цього скрипт grecaptcha не вшивається у HTML і forms не перевіряються.

Отримати ключі: google.com/recaptcha/admin/create -- оберіть тип reCAPTCHA v3, додайте домени (включно з локальним 127.0.0.1 для розробки).

Захищені форми

Перевірка автоматично застосовується до наступних форм:

  • login -- /login (вхід)
  • register -- /register (створення акаунта)
  • contact -- /contact (контактна форма)
  • course_request -- /courses/<slug>/request (запит на проведення)
  • event_register -- /register-instance (реєстрація на захід)

При fail-open: якщо Google API недоступний -- сабміт пропускається (щоб не блокувати реальних користувачів). Усі рішення логуються в audit-логи.
