Налаштування у Apple Developer Console:

  1. Створіть Services ID (Identifiers → +) -- це і буде поле "Services ID".
  2. У властивостях Services ID увімкніть Sign In with Apple і у Configure додайте Return URL: {{ cfg.redirect_uri }}.
  3. Створіть Key (Keys → +) з увімкненим Sign In with Apple. Завантажте .p8-файл -- його вміст вставте у поле "Private key" нижче. Файл завантажується ОДИН раз -- зберігайте копію локально.
  4. Team ID знаходиться у верхньому правому куті Developer Console.
