Як інтерпретувати

  • OK -- API доступне, наші ключі приймаються.
  • Degraded -- зв'язок з API є, але отримана відповідь несподівана (можливі змінені формати, частковий збій).
  • Down -- API недоступне або наші ключі/конфіг невалідні. Дивись поле "Помилка" для деталей.
  • Не налаштовано -- інтеграція ще не активована; перейдіть у відповідну admin-сторінку для конфігурації.

Health-check робить мінімально-інвазивні запити (discovery / siteverify з відомо невалідним токеном / check_status неіснуючого платежу). Жодних реальних транзакцій або відомостей про користувачів не зачіпає.
