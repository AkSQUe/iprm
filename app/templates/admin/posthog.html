Будь-яке збереження цієї форми робить прапорці явними: далі вирішує саме вона, а не змінні оточення. Доки галки не торкались, рішення успадковується з env – саме тому поруч з кожним станом вище написано його джерело.

PostHog → Settings → Project → Project API Key. Починається з phc_. Ключ, що починається з phx_, – це Personal API Key: він дає доступ до читання даних проєкту, і в HTML йому не місце. Порожнє поле означає «брати ключ з env».

Аварійний рубильник. Знята галка гасить збір повністю – зокрема й тоді, коли ключ приходить зі змінних оточення.

Окремий рубильник, щоб вимкнути саме запис екрана, не стираючи ключ і не гасячи заразом усю статистику. Поля вводу маскуються завжди; в адмінці маскується весь текст, тож картки учасників не потрапляють у відео. Запис сесій обробляє стороннім процесором поведінку відвідувачів – переконайтеся, що це відображено в політиці конфіденційності. Потребує ще й увімкненого session_recording_opt_in у самому проєкті PostHog.

Без цієї галки адмінка теж трекається, але кожна подія несе iprm_section=admin – відфільтрувати її можна в самому PostHog. Галка прибирає збір узагалі й економить квоту подій. Сторінка перевірки лишається під трекінгом у будь-якому разі.
